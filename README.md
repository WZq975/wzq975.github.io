# wzq975.github.io

Personal homepage of Ziqiang Wang: https://wzq975.github.io

Plain HTML and CSS with no build step; the whole page is `index.html`.
GitHub Pages serves the `main` branch as is (`.nojekyll` turns off Jekyll processing).

- `assets/img/`: portrait and the two paper figures
- `assets/fonts/`: self-hosted web fonts (Source Sans 3, Charis SIL), SIL Open Font License, see the `OFL-*.txt` files

Local preview: run `python3 -m http.server` in this folder and open http://localhost:8000
